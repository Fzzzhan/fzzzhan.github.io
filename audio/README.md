# Audio Files for Retro Radio Player

## Required Audio File

Please add the following audio file to this directory:

- **File name**: `purple-fire.mp3` (or `purple-fire.ogg` for better browser compatibility)
- **Song**: "Purple Fire" by ELFL
- **Format**: MP3 or OGG

## How to Add the Audio File

1. Download or obtain the audio file "Purple Fire" by ELFL
2. Name it `purple-fire.mp3` or `purple-fire.ogg`
3. Place it in this `/audio` directory

## Alternative Sources

If you don't have the audio file, you can:

1. Use any other synthwave/retrowave song you prefer
2. Update the file name in `index.html` in the `<audio>` element
3. Update the song information in the radio display

## Browser Compatibility

- MP3 format is widely supported
- OGG format provides better compression and quality
- The player supports both formats for maximum compatibility

## Notes

- The audio will loop automatically
- Autoplay may be blocked by some browsers (user needs to click play)
- Initial volume is set to 70%
